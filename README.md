# CSS - Command-Line Spreadsheet

コマンドプロンプトで動作する、軽量で高速なスプレッドシートアプリケーションです。

## 特徴

- ✅ .NET Runtime 不要（実行ファイルに内蔵）
- ✅ 702列（A～ZZ）× 1024行のグリッド
- ✅ 数式サポート（四則演算、関数）
- ✅ CSV ファイルの読み込み・保存
- ✅ Vim ライクなコマンドモード
- ✅ 列幅のカスタマイズ

## システム要件

- Windows 10/11 (64-bit)
- コマンドプロンプトまたは Windows Terminal

## インストール

1. `css.exe` をダウンロード
2. 任意のフォルダに配置
3. PATH に追加（オプション）

## 使い方

### 起動

```cmd
# 新規スプレッドシート
css.exe

# CSV ファイルを開く
css.exe data.csv
```

### 基本操作

#### ナビゲーションモード（デフォルト）

| キー | 動作 |
|------|------|
| ↑↓←→ | セル間を移動 |
| h j k l | セル間を移動（Vi ライク） |
| Enter または i | セルを編集 |
| : | コマンドモードに入る |
| Page Up/Down | 画面をスクロール |
| Home/End | 行の先頭/末尾に移動 |
| Delete | 現在のセルを削除 |

**Vi ライクなキーバインド:**
- `h` - 左に移動
- `j` - 下に移動
- `k` - 上に移動
- `l` - 右に移動
- `i` - 編集モードに入る

#### 編集モード

| キー | 動作 |
|------|------|
| Enter | 編集内容を確定 |
| ESC | 編集をキャンセル |
| 文字入力 | セルの内容を編集 |
| ←→ | カーソル移動 |
| Home/End | カーソルを先頭/末尾に |
| Backspace/Delete | 文字削除 |

#### コマンドモード

`:` を押してコマンドを入力します：

| コマンド | 説明 | 例 |
|----------|------|-----|
| `:w [filename]` | 保存 | `:w data.csv` |
| `:o filename` | 開く | `:o data.csv` |
| `:n` | 新規作成 | `:n` |
| `:width N` | 列幅を変更 | `:width 15` |
| `:q` | 終了 | `:q` |
| `:q!` | 強制終了（未保存でも終了） | `:q!` |
| `:wq [filename]` | 保存して終了 | `:wq` |

### 数式の使い方

セルに `=` で始まる文字列を入力すると、数式として評価されます。

#### 基本的な演算

```
=1+2          → 3
=10-5         → 5
=3*4          → 12
=20/4         → 5
=(1+2)*3      → 9
```

#### セル参照

```
=A1           → A1 の値
=A1+B1        → A1 と B1 の合計
=A1*B2+C3     → A1×B2 + C3
```

#### 関数

##### SUM - 合計

```
=SUM(A1:A10)      → A1～A10 の合計
=SUM(A1:B5)       → A1～B5 の全セルの合計
```

##### AVERAGE - 平均

```
=AVERAGE(A1:A10)  → A1～A10 の平均
=AVERAGE(B1:B5)   → B1～B5 の平均
```

##### MIN - 最小値

```
=MIN(A1:A10)      → A1～A10 の最小値
```

##### MAX - 最大値

```
=MAX(A1:A10)      → A1～A10 の最大値
```

##### IF - 条件分岐

```
=IF(A1>10, "High", "Low")     → A1が10より大きければ "High"、そうでなければ "Low"
=IF(A1=B1, 1, 0)              → A1とB1が等しければ 1、そうでなければ 0
```

### 使用例

#### 1. 簡単な計算表

```
     A        B        C
1    100      200      =A1+B1
2    150      250      =A2+B2
3    =SUM(A1:A2)  =SUM(B1:B2)  =SUM(C1:C2)
```

#### 2. 成績表

```
     A          B      C      D
1    Name       Math   Eng    Average
2    Alice      85     90     =AVERAGE(B2:C2)
3    Bob        75     80     =AVERAGE(B3:C3)
4    Charlie    95     88     =AVERAGE(B4:C4)
5    Average    =AVERAGE(B2:B4)  =AVERAGE(C2:C4)
```

#### 3. 条件付き評価

```
     A        B              C
1    Score    Grade          Pass/Fail
2    85       =IF(A2>=90,"A",IF(A2>=80,"B","C"))  =IF(A2>=60,"Pass","Fail")
3    92       =IF(A3>=90,"A",IF(A3>=80,"B","C"))  =IF(A3>=60,"Pass","Fail")
```

## CSV ファイル形式

- エンコーディング: UTF-8
- 区切り文字: カンマ (,)
- 数式: `=` で始まる文字列として保存

例：
```csv
100,200,=A1+B1
150,250,=A2+B2
=SUM(A1:A2),=SUM(B1:B2),=SUM(C1:C2)
```

## エラーメッセージ

| エラー | 意味 |
|--------|------|
| `#DIV/0!` | ゼロ除算 |
| `#REF!` | 無効なセル参照 |
| `#NAME?` | 未知の関数名 |
| `#VALUE!` | 型エラー |
| `#CIRCULAR!` | 循環参照 |
| `#ERROR!` | その他のエラー |

## トラブルシューティング

### Q: 実行ファイルが起動しない
A: Windows Defender や他のセキュリティソフトがブロックしている可能性があります。信頼できるファイルとして許可してください。

### Q: 日本語が文字化けする
A: コマンドプロンプトのコードページを UTF-8 に設定してください：
```cmd
chcp 65001
```

### Q: 画面が崩れる
A: ターミナルのサイズを大きくしてください。最小推奨サイズは 80×24 です。

### Q: 数式が計算されない
A: 数式は `=` で始まる必要があります。また、セル参照や関数名が正しいか確認してください。

## ビルド方法（開発者向け）

### 前提条件
- .NET 10.0 SDK

### ビルドコマンド

```bash
# デバッグビルド
dotnet build

# リリースビルド（自己完結型）
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ./publish
```

### 実行

```bash
# デバッグ実行
dotnet run

# リリース版実行
./publish/css.exe
```
